# 使用说明

On Screen Music 包含桌面歌词播放器，以及附属的音乐管理工具 MusicWorkshop。

## 第一次使用

解压完整便携包到可写目录，保留文件夹结构。运行 `OnScreenMusic.exe` 打开播放器，运行 `MusicWorkshop.exe` 打开音乐管理，也可从播放器托盘进入。

把自己的 MP3、LRC、TXT 歌单分别放入 `music`、`lyrics`、`playlists` 第一层。安装包不附带歌曲、歌词、模型或密钥。不要将软件放入需要管理员权限才能写入的目录。

音乐管理中的 FFmpeg、识别程序、模型可分别选择已有文件、自动查找或下载。下载会打开命令行，成功后保存路径，按回车关闭；large-v3 模型约 3.1 GB。AI 校对需单独填写并保存自己的接口密钥。

## 处理歌曲

通过添加文件、添加文件夹或选择现有歌曲加入列表。逐行设置格式与响度、本地识别、AI 校对及允许大量重复歌词。每首歌的参考歌词在行内按钮打开的窗口中填写。

现有歌曲不转码。识别和 AI 同时启用时，AI 使用本次新识别的草稿。选中条目且条件满足时，“开始所选处理”启用。

**整项处理成功后，最终歌词自动写入 `lyrics` 的对应 LRC。旧歌词先备份；失败或终止不更新原歌词。** 本地识别只在本机处理音频；AI 校对发送歌曲名和歌词文本，不上传音频。

新素材转换出的 MP3 保存在 `MusicWorkshopWork` 的对应任务目录，整理后放入 `music`。原始音频不修改、不移动、不删除。

`×` 和“移除全部”只移除空闲的处理列表条目。进行中的任务先到任务记录中确认终止。

## 歌曲资料和歌词编辑

资料库只读取 `music` 下的 MP3，不依赖歌单。每行“编辑歌词”打开同名 LRC，可以直接编辑、整体偏移或标为纯音乐。内容改变后保存按钮启用；保存前检查外部修改并备份旧文件。

试听提供播放/暂停、时间、音量、点击进度跳转和拖动。关闭编辑窗口停止试听。若任务后台更新了当前文档，请重新打开编辑窗口读取新内容；已有未保存编辑不会被界面自动替换。

## 歌单管理

选择歌单自动载入并检查。每行可调正整数权重、歌词开关或移除引用；末行 `＋` 添加歌曲，输入歌名开头筛选，重复和无匹配不能添加。

有错误时可“自动修复”，移除错误行后仍须保存才生效。保存无改动时置灰。删除歌单需要确认，原 TXT 会备份；歌曲和歌词保留。

```text
# 每个非空、非注释行是一条引用
示例歌曲.mp3|示例歌曲.lrc
纯音乐.mp3|-
```

相同引用重复出现表示随机权重。已有自定义歌词引用由歌单管理维护，资料库编辑器仍按音乐同名 LRC 打开。

## 播放器和快捷键

更新歌单或歌词后，在播放器点击“刷新”。歌词层可中键拖动，隐藏后鼠标穿透。

| 按键 | 功能 |
| --- | --- |
| 左 Ctrl + Num1 | 回退 5 秒 |
| 左 Ctrl + Num3 | 快进 5 秒 |
| 左 Ctrl + Num4 | 下一首；单曲循环开启时重播当前歌曲 |
| 左 Ctrl + Num5 | 播放／暂停 |
| 左 Ctrl + Num6 | 隐藏／恢复 |

仅物理小键盘和左 Ctrl 有效，NumLock 开关均可；“播放专用”仅响应 Num5。`↻×` / `↻1` 控制单曲循环。

## 清理、备份和更新

参数设置中的“清理临时文件”先统计占用，再选择并确认。默认只选临时文件；下载缓存和历史备份另行勾选。已保存任务结果、资料库、工具和模型保留；运行处理或下载时暂不清理。

旧 LRC 和 TXT 在 `MusicWorkshopWork/backups`，每份附有原位置记录。关闭相关软件后，可将备份文件复制回记录的原位置。删除历史备份后无法恢复对应旧版本。

更新前关闭播放器、音乐管理和下载窗口，备份自己的 `OnScreenMusic.ini`、三个资料目录及 `MusicWorkshopWork`，将新程序解压到新目录再迁入这些资料。保留软件内相对路径时，也一并迁入 `tools`；工具和模型不需要重新下载。

`MusicWorkshopTool.exe` 是后台处理和下载入口，不必手动运行。它与主程序共享 `MusicWorkshopRuntime`，请保持完整。
